SVG

¿Qué es SVG?

SVG significa Scalable Vector Graphics. Es un formato basado en XML utilizado para representar gráficos vectoriales en la web.

Características

  • Puede escalarse sin perder calidad.
  • Puede utilizarse directamente en páginas HTML.
  • Permite representar gráficos vectoriales.

Uso en desarrollo web

SVG es utilizado para iconos, logotipos, diagramas e ilustraciones.
